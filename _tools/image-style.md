# Site illustration style spec (locked 2026-08-12)

Style: "blend12" — evaluator's field-notebook hand drawing.
Chosen by Bertram from 7 samples; first production use: assets/og-map.png.

## Base prompt block (reuse for every article image)

> Precise engineering hand-drawing in pencil and fine ink on warm cream
> graph-grid notebook paper, patent-drawing accuracy with visible human hand
> warmth, one muted-blue ink-wash accent, a faint coffee-ring stain near one
> corner, generous margins like a real notebook page.
> Absolutely no readable text, letters, numbers, or logos anywhere.

## Recurring motifs (pick per subject)

- Tiny charming robot doodles in four families: walking (legs), rolling
  (wheels), flying (rotors), swimming (fins) — mirrors the site's
  walks/rolls/flies/swims line.
- Hand-drawn dashed rounded border = the unknown / unevidenced region.
- One small hollow circle = announcement-only evidence.
- Empty annotation bubbles with thin leader lines; hand-drawn axis arrows;
  small compass rose doodle.

## Production notes

- Format: 1200x630 PNG (works as OG image and in-page thumbnail).
- Generate via: codex exec with gpt-image (see repo history for exact command
  shape); always OVERWRITE the target filename so meta tags and thumbnails
  update without HTML edits.
- Subject changes per article; style block stays verbatim. Density: crowd one
  region, starve another — the contrast IS the thesis.
- Samples archive from the style selection round: assets/samples/ (remove from
  repo before it bloats; not linked anywhere).
