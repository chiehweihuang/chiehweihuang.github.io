Site statement

Accessibility

This site aims for WCAG 2.2 Level AA. Accessibility is also one way I test whether information and control remain available when attention, perception, memory or input methods vary.

Last updated 2026-08-13 · self-assessed

Implemented

  • Semantic landmarks, skip links and logical heading order.
  • Keyboard-operable navigation and controls with visible focus.
  • Light and dark themes that follow system preference and can be changed manually.
  • Explicit language tagging for English and Traditional Chinese pages.
  • Layouts designed to reflow without horizontal scrolling.
  • Reduced-motion preference respected; no essential information depends on animation.

Limits of this statement

  • This is a self-assessment supported by automated and browser checks, not a third-party certification.
  • Automated checks cannot establish full accessibility, comprehension or task success with assistive technology.
  • Google Analytics is loaded for basic visit statistics. Advertising features are not enabled by this site.

Report a barrier

If something is difficult to use, tell me what page and task were involved. You do not need to cite a standard: chieh.wei.huang@gmail.com.

無障礙聲明

本站以 WCAG 2.2 AA 為目標。已實作語意結構、跳至主要內容、鍵盤操作與可見焦點、深淺色主題、正確語言標記，以及避免水平捲動的響應式版面。本頁是自我評估，不是第三方認證；自動檢查也不能證明所有輔助科技與實際任務都能順利完成。

如果某個頁面或操作難以使用，請直接告訴我頁面與你想完成的事情，不需要引用規範：chieh.wei.huang@gmail.com。
